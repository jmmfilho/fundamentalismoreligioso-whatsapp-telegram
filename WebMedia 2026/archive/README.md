# Archive

Experiments carried out during the project that are **not reported in the
WebMedia 2026 paper**. They are kept for the record and are not maintained.

| Folder | Content |
|---|---|
| `results/lda`, `results/ptm`, `results/bertopic`, `results/liwc` | variants without filter and with the religious filter only |
| `results/perspective_api` | toxicity scores from the Perspective API and the 10 most/least toxic messages |
| `results/association_rules` | association rules between terms |
| `results/figures` | sentiment score histograms |
| `notebooks/pipeline_sbert_topics.ipynb` | unfinished SBERT + HDBSCAN clustering experiment (reads a `pre_processed_text` column that is not in the datasets) |
